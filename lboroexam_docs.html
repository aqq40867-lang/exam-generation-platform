Functions

功能分类:试卷 print vs 题目 create

lboroexam.cls 提供的命令可以分为两类:一类控制整份试卷的输出/打印方式,一类用于构建单道题目的内容与结构。

试卷 print · 整体输出控制
  • \maketitle自动生成标题页——模块代码、标题、时长、rubric、考试期换算、试卷编号
  • 固定页面格式A4 · 12pt · 边距 · 行距,用户不可更改
  • 页眉页脚首页/续页样式、Logo 插入、试卷编号 + 主考官/"continued..."
  • \printbooklet / \printanswers切换输出模式:作答booklet / 答案版 / 纯题目版
  • \shadedsolutions答案区域加阴影,区分是否打印答案
  • \placeanswerspace统一输出一份带作答空间的题目副本
  • \printextraspace[n]结尾追加 n 页空白作答页
  • 自动补空白页确保文档以空白页结尾,适配印刷装订
  • 旧模板兼容检查检测过时代码并警告/阻止编译
题目 create · 单题内容与结构
  • bookletquestions包裹全部题目,booklet 模式下题目的容器
  • \tmarks{分值}文字后标注分数
  • \emarks{分值}公式/显示等式后标注分数
  • subparts / tinysubparts小题编号环境:竖排缩进 / 横排紧凑
  • \breakquestion题目跨页时的提示与页脚处理
  • solution写答案,配合 \shadedsolutions 显示
  • \answerspace{长度}题目内插入指定高度的作答空白
  • \answerfill清空当前页剩余空间作为作答区
Guide

Gradescope Booklet 使用流程

来自 LaTeX for Gradescope.txt 的四步说明——如何生成带作答空间的考试booklet。

1
在导言区声明 \printbooklet
不声明则默认为纯题目版；\printanswers 则输出解答版。
2
用 bookletquestions 环境包裹题目
替代原本的 questions 环境；系统会将题目打印两次。
3
题目内插入作答空间
\answerspace{长度} 指定高度，或 \answerfill 占满剩余页面。
4
结尾放置作答副本 + 额外空白页
\placeanswerspace 输出带作答空间的题目；\printextraspace[n] 追加 n 页空白（默认 1）。
